# 超级雷霆战机

硬核科幻风格的浏览器纵向卷轴射击游戏。玩家可从六架战机中选择三架出战，在战斗中积累能量并切换机型。

## 本地运行

需要 Node.js。

- 安装依赖：npm install
- 启动开发服务器：npm run dev
- 类型检查：npx tsc --noEmit
- 生产构建：npm run build

## 操作

- 桌面：WASD 或方向键移动，空格或 Enter 开火，数字键 1–3 切换战机，Esc 暂停。
- 手机：在战场拖动战机移动，自动开火；能量满时点击上方战机切换，点击战场右上角暂停。

战斗画面使用 Canvas 2D，机体与弹体图像保存在 public/assets/。
