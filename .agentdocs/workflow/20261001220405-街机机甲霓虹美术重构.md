# 街机机甲霓虹美术重构

## 背景与目标

- 对会话-2 的硬核科幻军工美术效果重新设计，采用街机机甲霓虹风格。
- 保留六架玩家战机、四类敌机和既有战斗规则。
- 军工方案保存在 Git 分支 `codex/military-art-backup`，提交 `1911220`；本次修改位于 `codex/neon-arcade-refactor`。

## 约束与原则

- Canvas 逻辑尺寸保持 600×800，碰撞范围、速度、伤害和机型特性保持不变。
- 十架机体在实战、机库和情报页共用同一套本地资源。
- 以轮廓和高对比配色保证小尺寸辨识度：玩家机以蓝青、荧绿、金黄、橙粉、紫红区分；敌机以紫黑、猩红和洋红强调威胁。
- 用户在手机上继续拖动移动、自动开火、触屏切换及暂停；桌面键盘操作保留。

## 代码变更

- `public/assets/ships/`：替换六架玩家机和四类敌机透明 PNG。
- `public/assets/projectiles/`：替换等离子弹、导弹及敌方弹体透明 PNG，仅用于视觉表现。
- `render/background.ts`：改为紫黑星空、霓虹透视跑道、快速星迹和场地边角光条。
- `render/ships.ts`、`constants.ts`：调整机体发光、尾焰、弹道和各机型视觉色；图片按原始比例居中绘制。
- `App.tsx`：粒子由圆点改为旋转菱形火花，敌机血条及页面标识改为街机语汇。
- `index.css`、`components/`：统一霓虹紫黑、青蓝、洋红、荧光绿的界面样式和标识。

## 资源制作

- 使用内置 imagegen 分别生成 13 张透明 PNG，生成文件复制到项目本地资源目录。
- 统一提示词要求：正俯视、单个主体、透明背景、2.5D 手绘赛璐璐质感、明确装甲块面、饱和发光线条和小尺寸可辨轮廓；分别加入机型或弹体的专属外形和配色。
- 资源映射仍由 `render/ships.ts` 维护，预览界面直接使用该映射。

## 关键风险

- 高亮弹幕在密集开火时可能连成一道光束，需在不同机型和难度下继续观察视觉遮挡。
- 大量发光和透明 PNG 可能增加低端手机绘制成本；当前未做真实设备性能采样。
- 生成图的画风可能有细微差异；已用统一提示词与界面主色协调。
