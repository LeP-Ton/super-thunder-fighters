# 敌军阵营造型与喷口修复

## 背景与目标

- 会话-7，分支 `codex/pro-art-rebuild`，基线 `766d595`，与上一轮一致。
- 用户指出集群拦截机的尾喷口圆环不齐，要求自爆无人机改为单尾喷口的特殊机型，并通过造型和涂装区分敌军与玩家。

## 根因与设计

- 旧建模流程直接缩放零件的局部 Y。圆环已绕 X 旋转 90°，其局部 Y 对应世界 Z，导致圆环被压扁，而使用世界顶点创建的喷口外壳仍保持圆形。
- 旧集群拦截机唇口宽高比为 1.3158（宽 0.8132、高 0.6180），同轴外壳宽高比为 1.0。
- 统一在长度调整前烘焙物体旋转和缩放，再沿世界 Y 缩放；影响不止集群拦截机，因此十类模型同步重新导出。
- 自爆无人机独立设计为三瓣装甲梭形弹体、环绕测距镜头、中央单推进器；不复用通用战斗机的机翼、座舱、双垂尾和航炮。
- 四类敌军统一采用石墨黑灰底漆、暗红识别甲、红色光电核心；常规敌机使用三目传感器、矮散热背鳍和三齿阵营徽记。

## 约束与原则

- 保留游戏数值、AI、碰撞、60 Hz 固定时间步、侧倾与控制规则。
- 模型源文件、GLB、机库缩略图和 2D 降级图同步更新。
- 玩家涂装保留；玩家模型只随统一坐标修复重新生成。
- 尾焰数量由 `exhaust_*` 挂点决定，自爆无人机 1 个，风暴/超级战斗机 4 个，其余 2 个。

## 关键风险

- 纵向缩放修复会改变旧版旋转零件的外观，需同时检查玩家模型和敌机。
- 单喷口造型与原机型比例不同，需要核对展示接地、旋转取景与尾焰数量。
- 深色底漆需要靠红色识别板和传感器保持战斗辨识度。

## 测试用例

### TC-001 喷口同轴与圆度

- 操作：在 Blender Python 环境运行 `scripts/qa_model_sources.py`。
- 预期：十类模型圆环宽高比约为 1，圆心与喷口轴线误差小于 0.0001。
- 结果：通过；69 个圆环，全部宽高比 1.0，轴线误差 0。

### TC-002 自爆无人机专用结构

- 操作：检查源文件独立部件，浏览器加载实际 GLB 并创建战斗实例。
- 预期：一个中央喷口、三瓣径向结构、无座舱/传统机翼/双垂尾/航炮；只有一条匹配宽度的尾焰。
- 结果：通过；实际 GLB 只有一个中央挂点，半径为 0.54，战斗实例生成一条尾焰，宽度缩放为 0.405。

### TC-003 展示、战斗与兼容

- 操作：`npm run qa:parking`、`npm run qa:browser`；查看四类敌军前后侧和俯视素材。
- 预期：冷启动、切机、DPR、接地和旋转取景正常，战斗侧倾、射击、暂停、结算及 Canvas 2D 降级正常。
- 结果：通过；18 组尺寸/DPR 检查、10 类模型切换、280 组旋转投影及延迟加载冷启动均通过。1440×900 Chrome 持续战斗采样 10 秒为 60 FPS；侧倾回正、切机、射击、暂停恢复、结算和 2D 降级通过，浏览器错误列表为空。
- 人工视觉检查：最终情报页中集群拦截机喷口圆环与外壳吻合；自爆无人机正后方和旋转检视均能辨识单推进器、三瓣结构及红黑分区。

### TC-004 类型与构建

- 操作：`npx tsc --noEmit`、`npm run build`、`git diff --check`。
- 结果：全部通过。生产构建保留主 JS 包超过 500 kB 的体积提示，无构建错误。
