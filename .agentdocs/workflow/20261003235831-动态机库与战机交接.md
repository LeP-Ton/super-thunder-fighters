# 动态机库与战机交接

## 背景与目标

- 会话-8，分支 `codex/pro-art-rebuild`，基线 `a5de8fe`，与上一轮一致。
- 用户要求首页机械臂动态检修、舱外偶尔有飞机经过，以及切机时当前战机出舱、下一架从后方行驶进入。

## 设计与约束

- 保留同一世界坐标、固定相机、共享 GLB 和画布，动画不影响游戏逻辑、数值或碰撞。
- 机械臂采用关节层级，液压杆两端跟随基座和上臂；交接期间收拢，避免侵入出舱通道。
- 舱外复用先锋号模型，首轮约 7 秒后启动，26 秒一个周期、飞行 8 秒，交替显示三机和双机编队。机群始终位于舱门 z=-28 以外，由实体舱框自然遮挡。
- 切机分为 0.55 秒回正、2.8 秒出舱、2.7 秒滑入。起飞时收起落架并点亮尾焰；通过舱口后才拉升；进场轮胎保持接地，减速停稳。
- 首架加载保持原位呈现；后续机型资源成功就绪才开始交接。较慢的旧加载结果不能覆盖最后一次选择；已起飞的机体完成出舱，进场期间的新选择排在停稳之后。
- 展示活动时间在页面隐藏/弹窗遮挡时暂停。环境渲染限制 30 FPS，切机/拖动使用完整刷新率；系统减弱动态时关闭环境动作并直接切机。

## 关键风险

- 持续环境动画增加展示 GPU 开销，需关注高分屏帧率与后台暂停。
- 交接中连续选择、弹窗遮挡或销毁组件容易残留对象，必须释放展示自有资源并保留共享 GLB。
- 起飞轨迹需要低空通过门框；滑行必须保持轮胎接地。

## 验证

### TC-001 状态机与几何路径

- 操作：真实 GLB 构建交接实例；逐帧推进并检查回正、出舱和滑入。
- 覆盖：起飞中连续改选、缺少目标资源时等待、取消回正、减弱动态直接完成。
- 预期：舱内低空、进场 y=0、最终机型为最新选择，销毁不释放共享几何。
- 结果：通过。起飞中连续改选最终进入新星；未准备资源时保持原机位；取消回正、减弱动态即时完成均正常，共享几何释放次数为 0。

### TC-002 机械臂与巡航

- 操作：比较不同活动时刻的关节角度，检查退让姿态与巡航的活动/间歇状态。
- 预期：左右臂错峰活动，巡航保持在舱外，减弱动态时隐藏编队。
- 结果：通过。关节角度随时间改变，退让姿态不同于检修姿态；编队初始/间歇隐藏，活动时全部位于 z=-28 以外。最终浏览器截图已确认编队和关节动作。

### TC-003 浏览器交接与兼容

- 操作：真实首页切机，录制完整过程；弹窗遮挡期间暂停首页，机库连续改选，关闭弹窗恢复；模拟手机与减弱动态。
- 预期：复用同一画布，最终目标正确，无错误和横向溢出。
- 结果：通过。首页完成先锋号→风暴交接；机库快速连选最终为幽影；弹窗遮挡暂停及恢复正常；减弱动态直接回到先锋号，390×844/DPR 3 无溢出，浏览器错误为 0。最终录制已归档。

### TC-004 停放、游戏与构建

- 操作：`npm run qa:parking`、`npm run qa:browser`、`npx tsc --noEmit`、`npm run build`、`git diff --check`。
- 结果：类型检查、构建和 diff 检查通过（保留已有的主 JS 包体积提示）。停放回归通过：18 组尺寸/DPR、10 类切机、280 组取景、冷启动背景稳定与画布复用。战斗回归通过：1440×900 Chrome 采样 60.0 FPS，射击、切机、侧倾回正、暂停恢复、结算、多语言和 WebGL 关闭后的 Canvas 2D 降级正常，错误为 0。

### TC-005 高分屏绘制性能

- 操作：1440×900、DPR 2，统计真实 WebGL 绘制发生的帧，分别采样环境和切机；不是只统计浏览器 RAF 回调。
- 优化：避免合成链重复计算阴影与反射，环境遮蔽降采样，主体维持高分屏。
- 结果：最终完整回归中环境 29.9 FPS，切机 46.7 FPS；独立切机采样约 53.4 FPS。结果会受同时运行的浏览器/GPU 负载影响，尚未达到高分屏稳定 60 FPS。
