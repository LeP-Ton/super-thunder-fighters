## 长期关键记忆

- 游戏规则位于 game/，Three.js 战斗渲染位于 `render/battleScene.ts`，可编辑模型位于 `assets/model-sources/`，GLB 与预览位于 `public/assets/`。
- 首页、机库和情报通过 ShipShowcase 实时展示，共享 modelLibrary 下载与解析缓存；缩略图和降级俯视图从同一模型产出。
- 当前模型以 Shipyard CC0 机械组件与自制机体组成；Meshopt 优化必须保留 exhaust_* 喷口挂点。Quaternius 旧版仅保留在 Git 检查点 4a9ea5a。
- 战斗保持 600×800 逻辑坐标；视觉尺寸和渲染像素密度可以独立调整，Canvas 2D 保留为兼容画面。
- 战斗按 60 Hz 固定时间步更新，画面按浏览器刷新节奏绘制；修改速度或计时逻辑时需保持不同帧率下的结果一致。
